## 0. 三台时钟（所有动画的唯一驱动）

| 时钟 | 常量 | 值 | 职责 |
|---|---|---|---|
| 自动缩回状态机 | `POLL_MS` | 100ms | 全局鼠标坐标轮询，四条缩回规则 |
| 悬停层级机 | `HOVER_FAST_MS` / `HIDDEN_POLL_MS` | 60 / 80ms | `HIDDEN → PEEK → PANEL` |
| 帧动画定时器 | `FRAME_ACTIVE_MS` / `AMBIENT` / `TUCKED` | 16 / 66 / 200ms | 统一推进 `motion.Scalar`；静止即停 |

动画底座：`motion.Scalar`（`value` / `set` / `to` / `snap`），基于 `QVariantAnimation`，Qt 内部单定时器、跑完自停。
曲线表：`motion.OUT_BACK / OUT_CUBIC / OUT_QUART / OUT_QUAD / IN_CUBIC / IN_OUT_CUBIC / IN_OUT_SINE / LINEAR`

## 7. 硬约束（做任何动效时必须遵守）

1. **Dock 全局坐标 0px 漂移** —— 锚点在 placement 指纹不变时冻结；动效只能改绘制或子控件内部状态，不得改顶层窗口位置或锚定方式。
2. **不新增帧调度器** —— 所有动画必须接入 `motion.Scalar` / `_frame_inner`，结束即停表。
3. **无持续动画** —— 不新增流光、脉冲、粒子、波纹、背景模糊。
4. **可中断** —— 所有动画从当前值起算；轮询调用的入场/退场必须幂等。
